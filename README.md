# Windows 10 RAM Optimizer & System Cleaner

A lightweight (~10 KB) optimization script designed exclusively for **Windows 10**. It helps clear Standby Memory (RAM Cache) using native C# & PowerShell APIs without requiring third-party tools like RAMMap.

---

## 🌟 Key Features

* **RAM Optimization:** Instantly clears Standby Memory / Cache using the `NtSetSystemInformation` API.
* **System Cleanup:** Clears junk files, temp folders, and Windows Update cache.
* **Service Tweaks:** Disables SysMain (Superfetch) and Telemetry to prevent High Disk & RAM usage.
* **Power Plan:** Automatically enables and activates the **Ultimate Performance** mode.

---

## ⚠️ Important Note

* **Supported OS:** This tool works **ONLY** on **Windows 10**.
* **Language:** The console interface is currently in **Vietnamese**, but it is very simple and easy to use.

---

## 🚀 How to Use

1. Download the repository or latest release.
2. Right-click on the main script and select **Run as Administrator**.
3. Follow the simple on-screen instructions.
